# MarkGleam 打印工作流

MarkGleam 提供两种互补的 PDF 工作流：

- 保留样式 PDF 将每页渲染为图片，优先保证主题、背景和预览结果一致。
- 打印 / 可搜索 PDF 使用浏览器原生打印，优先保证文字清晰、文件较小、可搜索复制和纸张利用率。

保留样式 PDF 中的“100 页以上优先快速导出”默认开启：达到 100 页后会适度降低清晰度，以显著缩短耗时并减小文件；关闭后严格使用界面中选择的清晰度和图片质量。该选项对 100 页以下的文档没有影响。

## 打印模式

打印模式会在当前浏览器中临时创建独立打印内容，不上传 Markdown、图片或字体。它支持：

- A4 与 Letter；
- 纵向与横向；
- 0–30 mm 页边距；
- 默认白底省墨，或选择保留主题背景；
- 标题避免孤立在页尾；
- 表格按行分页并重复表头；
- 图片、代码块、引用和 Mermaid 图表尽量保持为完整块；
- 独立一行的 `<!-- pagebreak -->` 强制分页。

点击“打印 / 可搜索 PDF”后，浏览器会打开系统打印对话框。用户可以选择真实打印机，也可以选择“另存为 PDF”。网页无法在完全本地且无需扩展的前提下绕过浏览器对话框直接下载原生文字 PDF。

## 已知边界

- 打印页眉、页脚和默认文件保存位置由浏览器控制。
- 浏览器是否打印背景仍可能受到系统打印设置影响。
- 单个超高图片、代码块或 Mermaid 图表可能被整体移到下一页；必要时应在内容中加入显式分页符。
- 自定义 CSS 仍会随内容进入打印树，但打印模式会统一纸张字号、行高、页边距和省墨颜色，以保证通用可读性。
